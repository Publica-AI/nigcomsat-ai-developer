Make it. Fit it. Ask it.

from sklearn.ensemble import IsolationForest

model = IsolationForest(n_estimators=200, contamination=0.005, random_state=42)
model.fit(X[train])                  # learn what normal looks like (Jan–Aug)
model.predict(X)                     # -1 = odd, 1 = looks normal
model.decision_function(X)           # a score: LOWER = more odd

🌲 n_estimators

how many random trees vote

🎚️ contamination

the share of hours you allow it to flag

🎲 random_state

same random cuts every run

So when does scaling matter?

Distances care about units. Cuts don't.

📏

k-means: scale it

It measures distance. In steady sun bus voltage wobbles ~0.04 V; array current spans 30 A. Unscaled, the big numbers shout loudest.

🌲

Forest: makes no difference

It cuts between min and max of each column, whatever the units. Scores with and without scaling agree: r = 0.99999999

# a pipeline: scaler + model travel together
km = make_pipeline(StandardScaler(), KMeans(4, n_init=10, random_state=42))
