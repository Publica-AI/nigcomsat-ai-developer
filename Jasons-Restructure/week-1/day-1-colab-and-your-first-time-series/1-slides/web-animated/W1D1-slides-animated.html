Colab's 3 golden rules

Follow these and Colab won't embarrass you

💾

1. Save a copy first

File → Save a copy in Drive. Otherwise your work vanishes when you close the tab.

⬇️

2. Top to bottom

Run cells in order with Shift + Enter. Skipping a cell is like skipping a step in a recipe.

🔄

3. Confused? Restart

Runtime → Restart session and run all. It fixes 80% of weird problems.

Rule 1 is the big one. Do it now, before anything else.

Teach pandas about time

The 3-line recipe you will use every day

📄

CSV

dates are just text

🗓️

parse_dates

text → real dates

🧷

index_col

time becomes the row label

📏

.asfreq("D")

declare the rhythm

ka = pd.read_csv(data_path("ka_band_availability_daily"),
                 parse_dates=["timestamp"],      # 1. text -> dates
                 index_col="timestamp")          # 2. time is the row label
ka = ka.asfreq("D")                              # 3. one row per day, gaps show up
