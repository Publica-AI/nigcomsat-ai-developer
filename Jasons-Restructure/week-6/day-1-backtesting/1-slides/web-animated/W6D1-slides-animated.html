The whole idea in a few lines

walk_forward_mae()

def walk_forward_mae(df, feature_fn, x_cols, start_frac=0.5, step=4, h=4):
    feat_all = feature_fn(df)
    n = len(feat_all)
    errors = []
    for cut in range(int(n * start_frac), n - h, step):
        tr, te = feat_all.iloc[:cut], feat_all.iloc[cut:cut + h]   # past | next h weeks
        model = LinearRegression().fit(tr[x_cols], tr["target"])    # refit on the past ONLY
        errors.append(mae(model.predict(te[x_cols]), te["target"]))
    return np.array(errors)

iloc[:cut] = everything before the cut. iloc[cut:cut + h] = the next h weeks. Nothing from the future gets in.

Golden rules of an honest backtest

Five rules, every time

⏳

Only the past at each origin, and refit every time.

🥊

Same folds, same scorer for every method, baselines included.

📊

Report the spread and when the bad folds happen, not just the mean.

🔭

Test at the horizon the user needs.

🔒

Never tune on the folds you report. Fix the design (folds, step, horizon) first.
