# Synthetic MCE Corpus

Fictional Monitoring, Compliance and Enforcement documents for training demos. Every organisation, person, reference number, licence number and amount is invented. No real NIGCOMSAT data belongs in this folder or anywhere in course files.

Each document carries a "SYNTHETIC DOCUMENT" banner on its first line.

## Current contents (initial set, for Module 1)

| File | Type | First used |
|---|---|---|
| NOC-INC-2026-0417_noc_incident_report.txt | NOC incident report | Module 1, Topics 2, 5, 6 |
| MCE-CN-2026-031_compliance_notice.txt | Compliance notice with a revision | Module 1, Topics 2, 6 |
| MCE-EC-2025-118_enforcement_case_file.txt | Enforcement case file | Module 1, Topic 6 |
| ANSWER-KEY.md | Instructor-only facts and traps | Instructor use |
